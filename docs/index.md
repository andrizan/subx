# subx

All-in-one fansub toolkit in a single Rust binary: extract subtitles/audio,
clean and retime them, translate via LibreTranslate or any OpenAI-compatible
AI model, QC the result, and mux it back.

- **[User manual](USAGE.html)** — install, workflows, command reference, config
- **[Repository](https://github.com/andrizan/subx)** — source, issues, releases
